# Nookabye legal pages

Public Privacy Policy and Terms of Use for Nookabye, by RoohAI Services.

- Legal home: https://roohailabs.github.io/nookabye-legal/
- Privacy Policy: https://roohailabs.github.io/nookabye-legal/privacy.html
- Terms of Use: https://roohailabs.github.io/nookabye-legal/terms.html
- Contact: roohailabs@gmail.com

GitHub Pages serves the `main` branch, repository root. The site is static HTML
and CSS with a local fox icon: no build step, JavaScript, tracking, external fonts
or private app files.

To preview locally:

```sh
python3 -m http.server 8095 --bind 127.0.0.1
```

Open http://127.0.0.1:8095/. Stop with Ctrl+C.

Edit HTML/CSS, review at mobile and desktop widths, update the document date when
the wording changes, then commit and push `main` to deploy. Check the Pages build
and public pages afterward.

The privacy wording reflects Nookabye's current implementation, including AWS
delivery, RevenueCat, integrity checks, Talsec app protection and local reading
reminders. Keep it aligned when adding analytics, accounts, new providers or
data collection. Subscription wording covers cancellation of renewal, early
termination/refunds, changing free-to-paid policies and the maximum seven-day
offline lease.

site. The fox artwork and Nookabye app/story content are owned by RoohAI Services
and are excluded from that source licence. See `LICENSE` and `NOTICE`.
